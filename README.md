## Descripción del caso práctico
Una empresa de desarrollo de software necesita organizar los archivos de sus proyectos y mantener un historial de los cambios realizados. Los desarrolladores modificaban los archivos sin un control adecuado de versiones, lo que dificultaba identificar los cambios y recuperar versiones anteriores. Este repositorio implementa una solución con Git y GitHub, usando ramas, commits y pull requests.

## Objetivo del repositorio
Organizar los archivos de un proyecto, registrar los cambios mediante commits y demostrar el uso de ramas y pull requests para trabajar de manera ordenada y colaborativa.
